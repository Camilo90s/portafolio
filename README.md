# uiwithcamilo · Página en construcción

Hecha con HTML, Tailwind CSS v4 y Vite.

## Cómo usarla

```bash
npm install      # instala Vite y Tailwind
npm run dev      # abre la página en local con recarga automática
npm run build    # genera la carpeta dist/ lista para subir
```

Lo que subes a tu hosting es el contenido de `dist/`.
